Privacy

How Xrypton handles your data.

Data We Collect

  • Moderation records — warnings, mutes, bans, jails, notes, and case history
  • XP & leveling — XP, level, message counts, daily/weekly activity history
  • Message content — deleted and edited messages (for snipe/log features, opt-in only)
  • Presence state — online/offline status (opt-in only)
  • Profile changes — username, discriminator, and avatar changes
  • AFK status — your AFK reason and mention history
  • AI conversations — messages sent to the AI chat feature
  • Streaks — daily streak counts and restore history
  • Reminders — reminder text and scheduled time
  • Booster roles — custom role name, color, and shared-with users
  • Highlights — keywords you're tracking
  • Emoji usage — which emojis you use and how often
  • Tags & custom commands — content you create

What We Never Collect

  • Real-world personal information (name, email, address)
  • Passwords or authentication credentials
  • Financial information
  • Data from outside Discord

How We Use It

  • Moderation — enforce server rules, maintain case history, and audit logs
  • Leveling — track activity, award XP, and display leaderboards
  • Logging — record message edits/deletions, member joins/leaves, role changes, and other server events for administrators
  • AI chat — process your messages and generate responses
  • AFK — let others know you're away and notify you of mentions
  • Streaks — track and display your daily streak progress
  • Snipe — retrieve recently deleted or edited messages
  • Booster roles — manage custom roles for server boosters
  • Highlights — notify you when tracked keywords are mentioned
  • Tags — store and serve custom text commands you create

Security

  • All data is stored on private, access-controlled infrastructure
  • Only server administrators can configure what is logged

Your data is never sold, shared, or transmitted to third parties for advertising or analytics purposes.
